SCHEDULING GUARANTEES

Rules the generator will not break

Every generated or edited timetable is checked against the same set of constraints. If a placement would break one, ClassGrid refuses it and tells you why.

✓
No teacher clashes
A teacher is never scheduled with two classes in one period.
✓
No class clashes
Each class section holds exactly one lesson per period.
✓
Teacher availability respected
Blocked periods are treated as unavailable, not as preferences.
✓
Locked lessons stay in place
Regeneration moves unlocked lessons only.
✓
Balanced lesson distribution
Subjects spread across the week instead of stacking on one day.
